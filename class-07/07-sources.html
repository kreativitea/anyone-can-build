Class 7 — Sources

Not homework. These are the sources behind Class 7's claims, so that any of them can be checked. The first part rests on the people who built the system it describes, the second on courses that teach git to beginners, and the third on each app's own description of its markdown.

Your computer

  • CS50, Introduction to Cybersecurity (2023), Lecture 4 notes, Preserving Privacy (CC BY-NC-SA 4.0) — permissions met as the phone's prompt, on You have said yes to this before.
  • MIT, The Missing Semester of Your CS Education (2020), Course Overview + The Shell (CC BY-NC-SA 4.0) — ls -l read as owner, group and everyone else, root, and sudo with one warning: the order of What is mine?, the two slides that read one line of ls -l, and Not mine to change.
  • The sudo project, the sudo manual — sudo runs a command as the superuser, and can first require the user's own password, on Not mine to change.
  • Randall Munroe, Sandwich, xkcd 149 (CC BY-NC 2.5) — the comic on the slide after Not mine to change.
  • The sudo project, A Brief History of Sudo — sudo began with Bob Coggeshall and Cliff Spencer at SUNY Buffalo around 1980, on The user sandbox.
  • Android Open Source Project, Application Sandbox — every Android app is given a user of its own, on The user sandbox.
  • Dennis M. Ritchie and Ken Thompson, The UNIX Time-Sharing System (Communications of the ACM, July 1974) — owner and other-user protection bits, and a super-user above them: the 1970s on The user sandbox. Not read in preparation, because ACM's page refused the fetcher; it is free to read in a browser.
  • MITRE ATT&CK, Privilege Escalation (TA0004) — an attacker who got in wants higher permissions, root first among them, on What an attacker wants.
  • Qualys, the advisory on CVE-2021-3156, Baron Samedit (26 January 2021), and the sudo project's own Buffer overflow in command line unescaping — the hole in sudo from 2011 to 2021, on What an attacker wants.
  • Anthropic, Claude Code documentation, Security — the agent has only the permissions you grant it, and in Manual mode it starts read-only and writes only in the folder it was started in, on Could it wipe my computer?
  • Anthropic, Claude Code documentation, Choose a permission mode (read 25 September 2026) — the three modes, and auto as the starting mode on Pro, Max and Team plans, on Who checks before it acts?
  • MIT, The Missing Semester of Your CS Education (2026), Agentic Coding (CC BY-NC-SA 4.0) — an agent's permissions are skipped only on an isolated machine, on Who checks before it acts?

Git and GitHub

  • Software Carpentry, Version Control with Git (CC BY 4.0) — who pressed undo today? as the way in, on Why you need all four promises; version control taught on text rather than code, as on the README slides; and git status read before anything is believed.
  • The Odin Project, Git Basics (CC BY-NC-SA 4.0) — git status read after every move, at each step of both passes.
  • CodeYourFuture, Pushing and pulling (CC BY-NC-SA 4.0) — the push and pull messages taught as a set, each with one move, on I push — and git refuses me.
  • Harvard, CS50's Web Programming with Python and JavaScript (2020), Lecture 1 notes, Git (CC BY-NC-SA 4.0) — a message that is not a refusal is said out loud not to be one, as nothing to commit is in the same step.
  • UIUC CS 124, Using Git and GitHub (Fall 2026) — pull before you start, push when you are done, in a course whose students work with an AI assistant, on The two steps nobody told you about.
  • Louis-Michel Couture, In case of fire (MIT) — the poster on Why push, and not just commit? The joke itself is older, and its author is not known.
  • Git's own documentation, git switch and git merge — the commands of the branch beat, and the fast-forward merge on Merge, and main has it, which moves main forward without a new commit.
  • GitHub Docs, Configuring a publishing source for your GitHub Pages site — a GitHub Pages site is published from one branch, which is why a branch is invisible on the live page until it is merged, on main is what the world sees.

Markdown

  • GitHub, GitHub Flavored Markdown Spec — GitHub's markdown is CommonMark with extensions, the checkbox among them, and > is a quote, on Markdown comes in flavours.
  • Notion, Keyboard shortcuts (read 25 September 2026) — in Notion, [] makes a checkbox, " a quote and > a toggle list, on Markdown comes in flavours.
  • AGENTS.md, agents.md — "a README for agents", the file an agent reads for a project's instructions, on And the agent? at the end of the markdown part. Missing Semester 2026 uses the same description.
  • Anthropic, Claude Code documentation, How Claude remembers your project — CLAUDE.md, read each time Claude Code starts, on the same slide.
