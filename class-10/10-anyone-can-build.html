In the databaseデータベースで

  1. 1someone sends the database a query: SELECT * FROM posts ORDER BY id DESC LIMIT 20
  2. 2the database finds the newest twenty
  3. 3it hands back just those twenty, in order
The database executes the query. It does not choose the query.データベースはクエリを実行する。クエリを選ぶのはデータベースではない。
Anyone Can Build · Class 105 / 31
newest first · 3 of 3新しい順 · 3つのうち3つ目

In the backendバックエンドで

  1. 1the page asks the backend: the newest posts, please
  2. 2the backend writes the query: newest first, only twenty
  3. 3the database runs it and hands back twenty rows
  4. 4the backend sends those twenty to the page
  5. 5the page shows them
The backend formulates the query. The database executes it.バックエンドがクエリを組み立てる。データベースがそれを実行する。
Anyone Can Build · Class 106 / 31

Why the backend decidesなぜバックエンドが決めるのか

  1. one rule for every screen
    (the web page, the phone app, the next app)
  2. send only what is needed
    (the newest 20, not every post ever written)
  3. the user cannot change it
    (anything that runs on the user's own device, the user can change)
the backend formulates the query; the database executes it.バックエンドがクエリを組み立て、データベースがそれを実行する。

Words to search検索する言葉

type thisこれを打ち込むwhat it means意味
separation of concernseach part of a program has one jobプログラムの各部品に、仕事が一つずつある
three-tier architecturefrontend, backend and database, each on its ownフロントエンド、バックエンド、データベースが、それぞれ独立している
business logicthe rules that make the product what it isプロダクトを、そのプロダクトにしているルール
request, responsea message to the server, and its answerサーバーへのメッセージと、その答え
interface, contractwhere two parts meet, and what each side sends and returns二つの部品が出会うところと、それぞれの側が何を送り、何を返すか
data model: entity, attribute, relationshipwhat a product stores, the details of each, and how they linkプロダクトが何を保存するか、そのそれぞれの詳細、そしてそれらがどうつながるか
normalizationeach fact stored once; everything else points at itそれぞれの事実は一度だけ保存し、ほかはすべてそれを指す
constrainta rule the database enforces on its tablesデータベースがテーブルに課すルール
model-view-controller (MVC)the backend’s three jobs: take the request, apply the rules, shape the answerバックエンドの三つの仕事：リクエストを受け取り、ルールを適用し、答えの形を整える
