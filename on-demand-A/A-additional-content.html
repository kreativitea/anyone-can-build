On-Demand A — Additional content

The reading for the module on how a computer stores text and numbers. Read the first two; the third is for fun.

Read

  • Monica Dinculescu, Emoji: how do you get from U+1F355 to 🍕? (2016; ~10 min; free). An engineer who worked at Google follows one emoji from the number the computer stores to the picture on your screen. Every emoji has a number, its code point, written like U+1F355; some emoji are two or more code points joined together, which is how a flag, a skin tone or a family is made. You can skim the short code samples and still follow the idea. Harfbuzz and Skia are two parts of the browser, one that decides which numbers make one picture and one that draws it. The browser details are from 2016; the numbers have not changed. The writing is casual and has some slang and swearing: nerd out means get very interested in something, and them's a pickle means that is a difficult problem.
  • Joel Spolsky, The Absolute Minimum Every Software Developer Absolutely, Positively Must Know About Unicode and Character Sets (No Excuses!) (2003; the syllabus reading; ~20 min; free). A programmer's history of how computers stored text: first one code for each English letter (ASCII), then many different codes for other languages, then one list of code points for every language (Unicode), and finally the common way of storing those code points as bytes (UTF-8). The emoji post is the same idea with pictures. His main point is that text always has an encoding, the rule for turning the stored bytes back into letters, and a program that guesses the wrong one shows nonsense. No excuses means nobody may say they did not know.
  • Monica Dinculescu, I made a 2001-era emoji font! That you can use! (2016; ~6 min; free; for fun). The first emoji were made in Japan, for DoCoMo phones in 1999. She found an old DoCoMo phone, drew its 166 emoji again pixel by pixel, and made them into a font that any web page can use, with each one matched to its Unicode code point. The steps in the middle need tools you have not used; read for the story. It is casual too, with slang and swearing: tbh means "to be honest".

Do: write your journal entry

When you finish, write one dated entry in journal.md in your tracker repository (anyone-can-build-tracker), the same as at the end of a Friday. Start with the SDLC stage you are in, then answer the five questions:

  1. What did you do?
  2. What did you already know?
  3. What did you think you knew, and what changed?
  4. What did you learn?
  5. What do you carry forward?

You may ask the AI to list what you worked on; everything else is in your own words. Commit and push.
