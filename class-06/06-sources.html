Class 6 — Sources

Not homework. These are the sources behind Class 6's claims, so that any of them can be checked. Most of this class came from practice — building classifiers, and the room's own on Friday — so the list is short: the tool, the network inside it, and the standard written account of what the class measured.

Teach a model to see

  • Google Creative Lab, Teachable Machine (first version 2017; this version 2019) — the tool: an image model that trains in the browser.
  • Google Creative Lab, Teachable Machine: Frequently Asked Questions — the answer on Before you build: where does your data go?: the photos stay in the browser, and uploading a model publishes the model, not the photos.
  • Michelle Carney and colleagues, Teachable Machine: Approachable Web-Based Tool for Exploring Machine Learning Classification (CHI 2020 Extended Abstracts) — the makers' own account of the tool.
  • Mark Sandler and colleagues, MobileNetV2: Inverted Residuals and Linear Bottlenecks (CVPR 2018), after Andrew G. Howard and colleagues, MobileNets (2017) — the network inside Teachable Machine's image model, trained before you started, which is why about thirty examples of each shape were enough.
  • Jia Deng and colleagues, ImageNet: A Large-Scale Hierarchical Image Database (CVPR 2009) — the photographs that network first learned to see from: the same ImageNet as in What is AI?
  • Google Creative Lab, teachablemachine-community (Apache 2.0) — the code behind the image model, whose last step shares a fixed hundred points among your labels: why the three bars always add up to a hundred.

Make it see better

  • Google, Machine Learning Crash Course, Dividing the original dataset (CC BY 4.0) — why some examples are kept back, and why a check set used again and again wears out.
  • Google, Machine Learning Crash Course, Accuracy, recall, precision, and related metrics (CC BY 4.0) — accuracy as the right answers out of everything tried, and what one accuracy number hides.

Add noise

  • Google, Machine Learning Crash Course, Thresholds and the confusion matrix (CC BY 4.0) — the four squares on The four-square error chart: true and false positives, and true and false negatives. It puts the truth in columns, where the slide puts it in rows.
