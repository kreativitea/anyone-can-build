Adding noise results in lower accuracy — but there are some ways to manage noise.ノイズを加えると、正解率は下がる — でも、ノイズに対処する方法はいくつかある。

  • A person in the picture lowered the accuracy人が写り込むと、正解率が下がった
  • More hands would not have fixed it手を増やしても、直らなかったはず
  • A null case — None — is one way to manage itヌルケース — None — は、それに対処する方法の一つ
  • Four squares, for any one labelどのラベルでも、一つにつき四つのマス
