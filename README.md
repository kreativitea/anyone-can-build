# Anyone Can Build

**The Art of Product Engineering with AI** — Kansai Gaidai University, Asian
Studies Program, Fall 2026. Instructor: Michael Omoto.

The course materials for the students: the slides as they were shown in class,
what to read or watch afterwards, and the demos built in front of the room.

**Read it here: <https://kreativitea.github.io/anyone-can-build/>**

Every page is one self-contained HTML file. Open it in a browser; there is
nothing to install and nothing to build. In a deck, the arrow keys move,
**t** switches between light and dark, and **j** switches to Japanese where a
deck has been translated.

## Where this comes from

Nothing in this repository is edited by hand. It is generated from the course
repository and pushed here whole, so an edit made here is lost at the next
publication. Something wrong on a page is fixed at the source.
